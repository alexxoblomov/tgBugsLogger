# Инструкция по конфигурации бота tgBugsLogger

## Что делает бот

Бот отслеживает сообщения в определённых топиках Telegram-канала, проверяет их через ИИ на предмет корректности баг-репорта, и пересылает одобренные репорты в Slack. Все сообщения (и одобренные, и отклонённые) записываются в лог-файл. Это полезно для обработки жалоб игроков во время релизов - определенно, применение боту можно будет найти QA-команде, но возможно Support и Community позициям он так же может быть полезен. Телеграм зачастую - очень популярное место, где формируются игровые сообщества.

## Модули и их назначение

### 1. Настройки подключения (`config_data/config.py`)

**Что делает:** Загружает секретные ключи для подключения бота к Telegram и Slack.

**Что можно настроить (файл `.env` в корне проекта):**

| Параметр | Обязателен | Описание |
|---|---|---|
| `BOT_TOKEN` | Да | Токен Telegram-бота. Получается через @BotFather в Telegram |
| `SLACK_WEBHOOK_URL` | Да | Ссылка-вебхук для отправки сообщений в Slack-канал. Создаётся в настройках Slack-приложения |
| `OPENROUTER_API_KEY` | Да | Ключ API для ИИ-модерации через OpenRouter. Если не указан — ИИ-проверка отключена, и сообщения **не** будут пересылаться в Slack |

**Пример файла `.env`:**
```
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/XXXXX/YYYYY/ZZZZZ
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxx
```

### 2. Обработчик сообщений (`handlers/user_handlers.py`)

**Что делает:** Определяет, какие чаты и топики бот слушает, и управляет логикой обработки входящих сообщений.

**Что можно настроить (прямо в файле):**

| Параметр | Пример значения | Описание |
|---|---|---|
| `chat_id` | `-111111111111111` | ID Telegram-канала, который бот мониторит. Чтобы узнать ID канала, можно переслать сообщение из него боту @userinfobot |
| `allowed_topics` | `[12345, 54321]` | Список ID топиков (тем форума) внутри канала, за которыми следит бот. Только сообщения из этих топиков обрабатываются |
| `topic_names` | `{12345: "Баги с ver. XX", 54321: "Баги c ver. YY"}` | Понятные названия топиков. Используются при отправке в Slack и в логах, чтобы было видно, из какого топика пришёл репорт |

**Как добавить новый топик для мониторинга:**
1. Узнать ID топика (это число в URL при открытии топика в Telegram Web)
2. Добавить ID в список `allowed_topics`
3. Добавить соответствующее название в словарь `topic_names`

**Логика обработки:**
- Бот реагирует на текстовые сообщения, фото, видео и документы
- Ответы одних пользователей другим (реплаи) **игнорируются** — в Slack попадают только самостоятельные сообщения
- Сообщение проверяется ИИ-модератором, и если одобрено — отправляется в Slack

---

### 3. ИИ-модератор (`utils/ai_moderator.py`)

**Что делает:** Проверяет, является ли сообщение корректным баг-репортом. Использует языковую модель через сервис OpenRouter.

> Для разных моделей может требоваться разный промпт - отлаживайте перед запуском, экспериментируя с формулировками.

**Что можно настроить (в файле):**

| Параметр | Пример значения | Описание |
|---|---|---|
| Модель ИИ | `stepfun/step-3.5-flash:free` | Название используемой языковой модели. Влияет на качество и скорость проверки |
| Температура | `0.1` | Степень «креативности» ИИ. Низкое значение = более строгие и предсказуемые ответы |

**Критерии проверки (заданы в системном промпте внутри файла):**

Бот **одобряет** сообщение, если оно содержит:
- Описание технической проблемы (баг)
- Информацию об устройстве
- ID или никнейм игрока

Бот **отклоняет** сообщение, если это:
- Флуд, приветствия, оффтоп
- Вопросы или обсуждения
- Цитаты из других сообщений
- Жалобы на геймплей (не баги)
- Неполные репорты

> Если ключ `OPENROUTER_API_KEY` не указан в `.env`, модератор отключён — все сообщения считаются невалидными и в Slack не отправляются.

---

### 4. Отправка в Slack (`utils/slack_logger.py`)

**Что делает:** Формирует красивое сообщение и отправляет его в Slack-канал через вебхук.

**Формат сообщения в Slack:**
- Красная полоска сбоку (индикатор бага)
- Поля: **Топик**, **Текст сообщения**, **Ссылка на сообщение в Telegram**, **Имя пользователя**
- Подпись с именем бота и временем

**Что можно настроить:** Цвет полоски (текущий — красный `#ff0000`), название бота в подписи.

---

### 5. Логирование (`utils/link_logger.py`)

**Что делает:** Записывает информацию о каждом обработанном сообщении в файл `message_links.log`.

**Что попадает в лог:**
- Статус проверки (`APPROVED` / `REJECTED` с причиной)
- Ссылка на сообщение в Telegram
- Название чата
- Имя пользователя

> Логируются **все** сообщения, независимо от результата ИИ-проверки. 

---

### 6. Генерация ссылок (`utils/message_links.py`)

**Что делает:** Автоматически создаёт прямую ссылку на сообщение в Telegram. Используется в логах и при отправке в Slack.
